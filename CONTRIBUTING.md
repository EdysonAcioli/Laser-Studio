# Contribuindo para o Laser Studio

Obrigado por querer contribuir com o Laser Studio! Este projeto é feito para a comunidade e sua colaboração é muito importante.

## Como começar

1. Fork este repositório no GitHub.
2. Clone o fork localmente:

```bash
git clone https://github.com/seu-usuario/laser-studio.git
cd laser-studio
```

3. Instale dependências:

```bash
npm install
```

4. Crie uma branch com um nome descritivo:

```bash
git checkout -b feature/nome-da-funcionalidade
```

5. Faça suas alterações e commit:

```bash
git add .
git commit -m "Descrição clara da alteração"
```

6. Envie para o seu fork e abra um Pull Request.

## Diretrizes gerais

- Mantenha os commits pequenos e focados.
- Use mensagens de commit claras e descritivas.
- Inclua uma descrição do problema e a solução no PR.
- Verifique se não há erros de formatação nem avisos de TypeScript.

## Tipos de contribuições

- Correções de bugs
- Novas funcionalidades
- Documentação
- Testes
- Melhorias de performance

## Código de conduta

Todos os colaboradores devem seguir o `CODE_OF_CONDUCT.md`.
